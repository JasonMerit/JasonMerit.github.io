In part 1 the cube is drawn in isometric view (orthographic projection and viewing the cube along its diagonal) and the only transformation is done in the view matrix using the lookAt(eye, at, lookup) method. The object is offset by -e with V = [I -e; 0 1], where I is the 3x3 identity matrix, and e is the eye position.
The perspective matrix constructed by calling ortho(l, r, b, t, n, f) also has a translation, but because it is orthographic projection, due to l = -r, b=-t, and n=-f, the elements of the translation part are all 0.

Part 2 the cube is viewed from different perspectives, with the camera at a 45 degree vertical field of view. No translation is made in the perspective when calling perspective(fovy, aspect, near, far), and the view is the same as before.
The different perspectives are achieved by translating the cube around using the model matrix. This is achieved by calling translate(t_x, t_y, t_z) gives as
M = [1 0 0 t_x; 0 1 0 t_y; 0 0 1 t_z; 0 0 0 1].

Matrix multiplication is not commutative, so the order of operations is important. All points x in the cube were transformed by the matrix product PVMx, where the multiplication order is significant: the point x is first multiplied by M, then by V, and finally by P
